# COA-Z "Interwoven Beyond" Website Design System

> **Campaign:** #COA-ZInterwovenBeyond  
> **Core Theme:** Interwoven Connections / Threads of Unity  
> **Aesthetic:** Handcrafted Embroidery × Modern Minimalism  

---

## 1. Design Philosophy

### The Digital Canvas
Treat every webpage as a piece of linen fabric. The design does not merely *display* the interwoven theme—it **embodies** it. Each organizational identity is a thread; the website is the fabric they create together.

### Guiding Principles
| Principle | Application |
|-----------|-------------|
| **Fabric First** | Backgrounds evoke canvas/linen texture. White space is not empty—it is the untouched cloth waiting to be stitched. |
| **Threads Frame, Never Fight** | Decorative thread elements weave along borders and edges. They guide the eye inward toward content, never competing with it. |
| **Handcrafted Precision** | Every element should feel intentionally placed, as if stitched by hand—not generated by algorithm. Slight organic imperfections are welcome. |
| **Unity in Diversity** | The vibrant thread colors appear throughout the site in balanced proportion, symbolizing diverse organizations woven into one community. |

## 2. Color Palette

### Primary Colors
```
Trust Blue        #2E4A8F   → Primary typography, headers, active states, links
Canvas Cream      #F5F0E8   → Primary background, section fills
Linen White       #FAF8F5   → Card backgrounds, elevated surfaces
```

### Thread Accents (The Diversity Spectrum)
Use these as decorative thread colors, accent borders, icon fills, and hover states:
```
Thread Red        #C41E3A   → Passion, action, leadership
Thread Blue       #1E5AA8   → Trust, depth, stability
Thread Green      #2D8A3E   → Growth, service, harmony
Thread Yellow     #E4C41A   → Energy, optimism, creativity
Thread Pink       #E85A9A   → Compassion, community, warmth
Thread Purple     #7B3FA0   → Vision, wisdom, aspiration
```

### Neutral & Utility
```
Fabric Dark       #3D3D3D   → Body text, strong emphasis
Stitch Gray       #8A8A8A   → Secondary text, dividers, captions
Shadow Thread     rgba(46, 74, 143, 0.08)  → Soft shadows, depth
```

### Usage Rules
- **60/30/10 Rule**: 60% Canvas Cream/Linen White, 30% Trust Blue, 10% Thread Accents
- Never use more than 2-3 thread accent colors in a single viewport to avoid visual chaos
- Thread colors should appear woven together, not scattered randomly

## 3. Typography

### Font Pairing
| Role | Font | Weight | Usage |
|------|------|--------|-------|
| **Display** | Playfair Display or Cormorant Garamond | 600-700 | Hero headlines, section titles, campaign slogans |
| **Body** | Inter or Source Sans Pro | 400-500 | Paragraphs, descriptions, UI text |
| **Accent** | Caveat or Sacramento | 400 | Pull quotes, hashtags, handwritten callouts |

### Type Scale
```
Hero Title:      48px / 56px line-height / Playfair Display 700
Section Title:   32px / 40px line-height / Playfair Display 600
Subsection:      24px / 32px line-height / Playfair Display 600
Body Large:      18px / 28px line-height / Inter 400
Body:            16px / 24px line-height / Inter 400
Caption:         14px / 20px line-height / Inter 500 / Stitch Gray
Accent Text:     20px / 28px line-height / Caveat 400
```

### Typography Details
- **Letter Spacing**: Slightly tighter (-0.02em) for large display text; normal for body
- **Text Alignment**: Center-aligned for manifesto/philosophy sections; left-aligned for informational content
- **Pull Quotes**: Rendered in Accent font with a vertical thread-stitch border on the left

### Section Rhythm

## 5. Visual Elements & Components

### A. Thread Borders (Signature Element)
- **Style**: SVG paths mimicking the embroidered thread curves from the poster assets
- **Behavior**: Static on mobile; subtle parallax drift (10-20px) on desktop scroll
- **Placement**: Top and bottom of major sections; occasionally along left/right edges
- **Colors**: Alternate between Thread Red, Blue, Green, and Purple along the path

### B. Embroidered Accents
- Use the provided flower/leaf assets (pink, blue, green, red, purple) as:
  - Section transition markers
  - Bullet points for lists
  - Decorative corners on cards
- Scale: 32px–64px depending on context
- Opacity: 100% on decorative elements; 60-80% when used as background watermarks

### C. Cards
```css
/* Conceptual Spec */
.card {
  background: #FAF8F5;
  border-radius: 8px;
  box-shadow: 0 4px 20px rgba(46, 74, 143, 0.06);
  border: 1px solid rgba(46, 74, 143, 0.08);
  padding: 32px;
  position: relative;
}
/* Optional: subtle fabric texture overlay at 3% opacity */
```
- **Hover State**: A colored thread border (2px) appears, stitching itself around the card edge via CSS animation

### D. Buttons
- **Primary**: Trust Blue background, Linen White text, pill-shaped (border-radius: 999px)
- **Secondary**: Transparent with 2px Trust Blue border, Trust Blue text
- **Hover**: Background shifts to Thread Green or Thread Red; slight upward translate (2px)
- **Focus**: 3px dashed Stitch Gray outline (evoking a stitch pattern)

### E. Dividers
- Replace standard horizontal rules with "stitch lines"
- Pattern: dash-gap-dash-gap (8px dash, 4px gap) in Stitch Gray or Thread Blue
- Alternatively: a short embroidered flower flanked by thread dashes

### F. Navigation
- **Desktop**: Horizontal, minimal, Trust Blue text. Active page has a thread-underline (2px, Thread Red)
- **Mobile**: Hamburger menu with a slide-out panel; menu items separated by stitch-line dividers
- **Logo**: COA-Z emblem centered; on scroll, nav background becomes Linen White with subtle shadow

## 6. Animation & Interaction Language

### Core Motion Principles
All animations should feel **organic** and **handcrafted**—never mechanical or overly slick.

| Interaction | Effect | Rationale |
|-------------|--------|-----------|
| **Page Load** | Threads "sew" themselves around the hero section border (SVG stroke-dashoffset animation) | Establishes the theme immediately |
| **Scroll Reveal** | Content fades up (20px) + opacity 0→1 over 600ms, ease-out | Gentle, unhurried discovery |
| **Section Transition** | A thread weaves horizontally across the screen, leading the eye to the next section | Literal interweaving narrative |
| **Card Hover** | Border stitches itself around the card; inner content lifts slightly (translateY -4px) | Tactile, handcrafted feedback |
| **Button Hover** | Background color morphs; a tiny thread loop animates at the corner | Playful, on-brand micro-interaction |
| **Link Underline** | Underline draws itself left-to-right like a stitching motion | Consistent thread metaphor |

### Scroll-Triggered Thread Weaving
- As the user scrolls, a continuous SVG thread path draws itself down the page, connecting sections
- The thread changes color at each section, representing different organizations/clusters
- This is the **signature interactive element**—the digital embodiment of "interwoven beyond"

### Reduced Motion
- Respect `prefers-reduced-motion: reduce`
- Fallback: Static thread borders, instant state changes, no parallax

## 8. Content Strategy & Voice

### Tone of Voice
- **Warm** but **professional**
- **Inclusive** and **inviting**
- **Purpose-driven** without being preachy
- Use "we" and "our" to reinforce collective identity

### Key Phrases to Weave Throughout
- "Interwoven Beyond"
- "Threads of Unity"
- "Stitched together"
- "Every thread matters"
- "Woven by shared purpose"

### Content Structure per Section
1. **Headline**: Bold, purposeful, community-centered
2. **Subhead/Body**: Explain the "what" and "why" with warmth
3. **CTA**: Action-oriented but gentle (e.g., "Join the weave" rather than "Submit")

## 9. Responsive Behavior

### Desktop (1200px+)
- Full thread border decorations
- Multi-column layouts
- Parallax thread effects active
- Generous section padding (100px+)

### Tablet (768px–1199px)
- Simplified thread borders (top/bottom only)
- 2-column grids become single or asymmetric
- Reduced parallax
- Section padding: 60px

### Mobile (< 768px)
- Minimal thread accents (top border only, single color)
- Single-column stacked layout
- No parallax; static decorative elements
- Section padding: 40px
- Navigation becomes full-screen overlay with stitched dividers

## 10. Accessibility Standards

- **Color Contrast**: All text meets WCAG AA (4.5:1 for body, 3:1 for large text)
- **Focus Indicators**: Visible, high-contrast focus rings with stitch-dash pattern
- **Alt Text**: All embroidered assets described meaningfully (e.g., "Embroidered pink flower accent" not just "flower")
- **Motion**: Respects `prefers-reduced-motion`
- **Semantics**: Proper heading hierarchy, landmark regions, ARIA labels for interactive thread elements

## 12. Quick Reference: Do's and Don'ts

| ✅ Do This | ❌ Avoid This |
|-----------|---------------|
| Let whitespace breathe like untouched fabric | Crowd the canvas with too many decorative elements |
| Use thread colors in balanced, intentional clusters | Scatter rainbow colors randomly without purpose |
| Animate threads slowly and organically | Use fast, mechanical, or bouncy animations |
| Frame content with threads; let them guide | Let threads cross over or obscure readable text |
| Keep typography clean and trustworthy | Use overly decorative or hard-to-read fonts for body text |
| Use the fabric texture subtly (3-8% opacity) | Apply heavy textures that reduce readability |
| Tell the story of connection through layout | Treat it as a generic corporate website with flowers pasted on |
