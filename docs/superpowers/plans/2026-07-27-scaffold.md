# COA-Z Website Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Initialize the Vite + React + TypeScript project, install all dependencies, create the full `src/` directory tree, and write minimal shell stubs for all pages, lib modules, config files, and hooks — leaving the app compilable but unimplemented.

**Architecture:** Single-pass scaffold using Option A from the design: `bun create vite` for the base project, cleanup of generated demo files, then installation of all deps and creation of stub files in dependency order (config → types → client → services → hooks → pages → entry points). Each task leaves the project in a TypeScript-compilable state.

**Tech Stack:** Bun, Vite, React 18, TypeScript, Tailwind CSS v4 (`@tailwindcss/vite`), React Router v6, TanStack Query v5, Contentful JS SDK, PostHog JS, shadcn/ui primitives (`@radix-ui/react-slot`, `class-variance-authority`), clsx, tailwind-merge, Lucide React, react-helmet-async.

## Global Constraints

- Runtime: Bun (not npm/yarn/pnpm)
- Vite template: `react-ts`
- Tailwind v4 — uses `@tailwindcss/vite` plugin, no `tailwind.config.js` required
- All env vars prefixed with `VITE_` and accessed via `import.meta.env`
- No feature code — stubs only
- shadcn/ui: install only, no `npx shadcn init`
- `.env` must not be committed (already in Vite's `.gitignore`)

- [ ] **Step 1: Create src/lib/analytics/posthog.ts**

```ts
import posthog from 'posthog-js'

export function initPostHog(): void {
  const key = import.meta.env.VITE_POSTHOG_KEY as string | undefined
  const host = (import.meta.env.VITE_POSTHOG_HOST as string) ?? 'https://app.posthog.com'
  if (!key) return
  posthog.init(key, { api_host: host })
}

export function trackEvent(event: string, properties?: Record<string, unknown>): void {
  posthog.capture(event, properties)
}
```

- [ ] **Step 2: Create src/lib/utils.ts**

```ts
import { clsx, type ClassValue } from 'clsx'
import { twMerge } from 'tailwind-merge'
```
